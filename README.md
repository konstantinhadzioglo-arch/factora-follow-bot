# Factora Follow Bot

Готовый Telegram-бот для взаимных подписок.

## Запуск локально

1. Установить Python 3.11+
2. `pip install -r requirements.txt`
3. Создать переменную окружения `BOT_TOKEN` с токеном BotFather.
4. Запустить `python bot.py`.

## Важно

Токен не публикуй в GitHub, чатах или скриншотах. Если токен утёк, отзови его через BotFather и создай новый.

Текущая версия сохраняет профили в SQLite и выдаёт случайные активные профили. Автоматическая проверка факта подписки Instagram/TikTok здесь не используется.
